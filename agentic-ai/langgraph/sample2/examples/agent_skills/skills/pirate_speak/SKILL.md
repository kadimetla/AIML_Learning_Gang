---
name: pirate_speak
description: Translate any given text into pirate-speak. Use this when the user asks for something to be translated, rewritten, or said "like a pirate".
---

Rewrite the user's text so it reads like pirate/nautical slang, while keeping
the original meaning intact:

- "hello" -> "ahoy"
- "friend"/"you" -> "matey"/"ye"
- "yes"/"no" -> "aye"/"nay"
- add flavor words sparingly: "arr", "shiver me timbers", "avast"

Keep sentences short and don't overdo it -- one or two pirate flourishes per
sentence reads better than swapping every single word. See
references/examples.md for a few worked examples.
