Step 1 · Parameters

Every learnable piece in one transformer layer

Backprop doesn't just touch attention — it touches every matrix that participated in the forward pass.

Inside self-attention

  • Wq, Wk, Wv — project embeddings into Query, Key, Value spaces
  • Wo — output projection that recombines multi-head outputs

Inside the feed-forward block

  • W1, b1 — first linear layer (expands dimension, e.g. 768→3072)
  • W2, b2 — second linear layer (projects back down, e.g. 3072→768)

Normalization

  • γ, β — learnable scale and shift in each LayerNorm

The embedding table

  • One row per vocabulary token — the very first thing touched in the forward pass, and the very last thing updated in the backward pass
A model like BERT-base stacks 12 of these layers — every single matrix above exists independently per layer, and backprop updates all of them, every training step.
Step 2 · Forward Recap

One layer's forward pass, in order

Backprop simply reverses this exact sequence — so the forward order tells us the backward order too.

① Input embeddings + positional encoding x
② Self-attention: Q=xWq, K=xWk, V=xWv → softmax(QKᵗ/√d)·V → attn_out
③ Residual add + LayerNorm x + attn_out
④ Feed-forward: W2·ReLU(W1·x + b1) + b2 → ffn_out
⑤ Residual add + LayerNorm x + ffn_out
⑥ (After all layers) Output projection → logits → softmax → probabilities
⑦ Cross-entropy loss against the true token → L
Backprop runs this list bottom to top — starting at ⑦ and working back to ①, applying the chain rule at every arrow.
Step 3 · Loss → Logits

Where the gradient signal originates

Next-token or masked-token prediction: cross-entropy loss against the vocabulary distribution.

The softmax + cross-entropy gradient

∂L/∂logit_i = p_i − y_i p_i = predicted probability of token i y_i = 1 if i is the correct token, else 0

This is the famously clean result of combining softmax with cross-entropy — the gradient is just "predicted minus actual."

Concretely, for "##er"

If the model assigned "##er" only 20% probability when it should have been the correct answer (100%):

∂L/∂logit(##er) = 0.20 − 1.0 = −0.80

Negative gradient → increasing this logit would reduce the loss → training pushes it up.

Every other vocabulary token that was incorrectly given some probability gets a small positive gradient too — training pushes their logits down slightly, since y_i = 0 for them.
Step 4 · Backprop Through FFN

Gradient flow through the feed-forward block

Same chain-rule mechanics as any feed-forward network — just embedded inside a much bigger architecture.

1

Gradient arrives from above

∂L/∂ffn_out — handed down from the residual connection after this block

2

Through the second linear layer

∂L/∂W2 = ReLU_out · ∂L/∂ffn_out (outer product) | ∂L/∂ReLU_out = W2ᵗ · ∂L/∂ffn_out

3

Through the ReLU

∂L/∂z1 = ∂L/∂ReLU_out × [1 if z1 > 0 else 0] — gradient zeroed wherever the activation was inactive

4

Through the first linear layer

∂L/∂W1 = x · ∂L/∂z1 | ∂L/∂x_ffn = W1ᵗ · ∂L/∂z1 ← this continues backward into the residual sum

Notice the pattern: every linear layer's weight gradient is an outer product of "what flowed in" and "what gradient flowed out" — identical in form to the toy 2-layer network, just with matrices instead of scalars.
Step 5 · Backprop Through Attention

How the gradient reaches Wq, Wk, Wv

More moving parts than the FFN — softmax and the Q·Kᵗ product each need their own local derivative.

1. Through the weighted sum of V

output = Σ weight_i · V_i ∂L/∂V_i = weight_i · ∂L/∂output ∂L/∂weight_i = V_i · ∂L/∂output

2. Through softmax

Softmax's Jacobian couples every output to every input — increasing one attention weight necessarily decreases the others (they must sum to 1):

∂weight_i/∂score_j = weight_i(δ_ij − weight_j)

3. Through the dot product

score = Q·Kᵗ / √d ∂L/∂Q = (∂L/∂score · K) / √d ∂L/∂K = (∂L/∂score · Q) / √d

4. Into the projection matrices

∂L/∂Wq = xᵗ · ∂L/∂Q ∂L/∂Wk = xᵗ · ∂L/∂K ∂L/∂Wv = xᵗ · ∂L/∂V
All three gradients (∂L/∂Q, ∂L/∂K, ∂L/∂V) ultimately flow back into the same shared input embedding x — since Q, K, and V were all computed from it. Their contributions simply add together.
Step 6 · Residual Connections

Why skip connections save the gradient

Deep stacks of layers risk the "vanishing gradient" problem — residuals are the architectural fix.

Without residuals

Each layer's gradient gets multiplied by that layer's local derivative. Stack 12+ layers, and repeated multiplication of values <1 can shrink the gradient toward zero by the time it reaches early layers — they barely learn.

With residuals

Each block computes output = x + F(x). Differentiating a sum just adds 1 to the gradient path:

∂output/∂x = 1 + ∂F(x)/∂x
That "+1" guarantees a direct, undiminished path for the gradient straight back to the input of every block — regardless of how small ∂F(x)/∂x becomes. This is why transformers can stack dozens of layers and still train end-to-end.
Step 6 · Final Destination

Where the gradient finally lands: the embedding table

After flowing backward through every layer, the gradient reaches the very first lookup of the forward pass.

∂L/∂logits
Starts at the loss, flows back through the output projection
↓
∂L/∂layer_12 ... ∂L/∂layer_1
Passes through every FFN and attention block, each adding its own chain-rule term
↓
∂L/∂embedding["##er"]
embedding["##er"] -= lr × ∂L/∂embedding["##er"]
Only the rows that were actually used in this batch's sentences get a nonzero gradient and get updated. A token's embedding only improves on steps where that exact token appeared — which is why frequent tokens like "##er" converge faster than rare ones.

The full gradient journey, end to end

The big picture

  • Transformers don't need a special version of backprop — it's the same chain rule used in any neural network.
  • What's different is the shape of the computation: attention adds softmax and dot-product derivatives into the chain.
  • Residual connections are what make 12, 24, or 96-layer stacks trainable at all — without them, gradients would vanish before reaching early layers.
  • Every parameter — Wq/Wk/Wv, FFN weights, LayerNorm scales, and embedding rows — is updated by the exact same rule: subtract a small step in the direction of the gradient.
