What a Derivative Actually Means

Not calculus jargon — a physical question with a physical answer.
The simplest derivative — driving a car
You are driving a car:
position = f(time)
speed    = d(position)/d(time)
Speed answers: "if time ticks forward by 0.001 seconds, how much does position change?"
That ratio — output change / input change — is the derivative. It is just the slope of the curve at one specific point.
"In neural networks, x = weight, f = error. We want: if I nudge this weight, does error go up or down?"
The formal definition
df/dx = lim(ε→0)  [f(x+ε) − f(x)] / ε
In plain steps
1
Nudge x forward by a tiny ε
2
Measure how much f(x) changes — the rise
3
Divide change by ε — rise/run = slope
4
Shrink ε to zero → instantaneous slope at that point

Error = (pred − goal)² Draws a Parabola

The slope at every point tells which direction to move pred — and by how much.
Computing the bowl (goal = 1.0)

The error bowl
Key pattern: negative slope = left of minimum = pred too low = must increase weight. Magnitude of slope = how far from minimum.

d(error)/d(pred) = 2 × delta — Step by Step

The power rule applied to the squared error function. Four lines of algebra.
1
Write error as a function of pred
error = (pred − goal)²

goal is a fixed constant.
pred is the variable.
We want: how does error
change when pred changes?
2
Substitute u = pred − goal
Let  u = pred − goal
Then error = u²

This simplifies the expression.
Note: d(u)/d(pred) = 1
(shifting by constant doesn't
change the rate)
3
Apply Power Rule: d(uⁿ)/du = n·uⁿ⁻¹
d(error)/du = d(u²)/du
            = 2 × u¹
            = 2u

The exponent (2) drops down
and multiplies.
New exponent = 2 − 1 = 1.
4
Substitute back: u = pred − goal
d(error)/d(pred)
  = 2 × (pred − goal)
  = 2 × delta

With pred=0.85, goal=1.0:
= 2 × (0.85−1.0)
= 2 × (−0.15) = −0.30 ✓

Reading the Derivative — Direction and Magnitude

d(error)/d(pred) = −0.30 makes three precise statements at once.
d(error)/d(pred) = 2×(pred−goal) = 2×delta = 2×(0.85−1.0) = −0.30
①
Sign tells direction
slope = −0.30  (negative)

→ Left of the bowl minimum
→ pred is BELOW goal
→ Must INCREASE pred

Rule:
negative slope → move right
              → increase pred
②
Magnitude tells distance
|slope| = 0.30  (moderate)

pred=0.0: slope = −2.0  BIG
pred=0.8: slope = −0.4  small
pred=0.85: slope = −0.30 ←here
pred=1.0: slope =  0.0  min!

Bigger miss = steeper slope
= larger weight update
③
Zero = minimum found
slope = 0  when pred = goal

→ At the bowl bottom
→ weight_delta = 0
→ No update needed
→ Training converged

2 × (1.0 − 1.0) = 0  ✓
Perfect prediction.

The Chain Rule — Linked Rates of Change

When output depends on a middle variable which depends on input, multiply the slopes.
The gear analogy
A
drive gear
→
B
3× faster
→
C
2× faster
A turns → B turns 3× faster
B turns → C turns 2× faster
A → C turns 3×2 = 6× faster
Multiply the rates. That is the chain rule.
The formal chain rule
if  y = f(u)  and  u = g(x)

then  dy/dx = dy/du × du/dx
              ↑           ↑
         rate y→u    rate u→x
The du cancels like a fraction: dy/du × du/dx = dy/dx
Applied to neural networks
y = error,  u = pred,  x = weight

d(error)/d(weight)
  = d(error)/d(pred) × d(pred)/d(weight)
  = 2 × delta         × input
  = 2 × delta × input

Drop 2 into alpha:
  = delta × input
  = weight_delta  ✓

d(pred)/d(weight) = input — The Second Piece

How much does pred change when we nudge weight? Exactly proportional to the input.
The forward equation
pred = input × weight
     = 8.5  × 0.1
     = 0.85

input is a FIXED constant per step.
weight is the variable.

d(pred)/d(weight) = input = 8.5
Concrete verification
weight = 0.100 → pred = 8.5 × 0.100 = 0.8500
weight = 0.101 → pred = 8.5 × 0.101 = 0.8585

change in pred   = 0.8585 − 0.8500 = 0.0085
change in weight = 0.001

rate = 0.0085 / 0.001 = 8.5 = input  ✓

The rate of change is exactly the input value.
What this means physically
Large input (8.5)
Weight has HIGH leverage. Small weight change → big pred change → large weight_delta.
Zero input (0.0)
Weight has NO leverage. Changing weight changes nothing. weight_delta = 0. No learning. This is the STOPPING property.
Negative input (−3.0)
Weight has REVERSED leverage. Increasing weight decreases pred. weight_delta flips sign automatically. This is NEGATIVE REVERSAL.

The Chain Rule Applied — Complete Derivation

Two pieces multiplied together give weight_delta. Every step accounted for.
d(error)/d(weight) = d(error)/d(pred) × d(pred)/d(weight)
= 2×(pred−goal) × input = 2×delta×input → drop 2 into α → delta × input = weight_delta
Piece 1: d(error)/d(pred)
= 2 × delta
= 2 × (0.85 − 1.0)
= 2 × (−0.15)
= −0.30
How sensitive is error to a change in pred? The slope of the error bowl at the current prediction.
× Piece 2: d(pred)/d(weight)
= input
= 8.5
How sensitive is pred to a change in weight? Exactly the input value — the "lever arm" of the weight.
= Result: d(error)/d(weight)
= −0.30 × 8.5
= −2.55

Drop 2: weight_delta
= delta × input
= −0.15 × 8.5
= −1.275
Negative → weight must increase. This is the complete gradient, translated from output space to weight space.

Why Is Error Computed? It Never Feeds weight_delta

Error is a dead end in the update chain — but it has three essential jobs outside it.
1
Monitoring — you need to watch convergence
for i in range(1000):
    pred  = input * weight
    error = (pred - goal) ** 2    # ← dead end in backprop
    delta = pred - goal
    weight -= alpha * delta * input
    if i % 100 == 0: print(f"step {i}  error={error:.4f}")
# Remove error line → weights converge identically. You just lose visibility.
2
Early stopping — deciding when training is done
    if error < 0.001:    # stopping criterion
        print(f"Converged at step {i}"); break
# The weights don't need error. Your stopping condition does.
3
Choosing what to learn — the loss function shapes the bowl
# MSE:          error = (pred-goal)²      → d(error)/d(pred) = 2δ
# MAE:          error = |pred-goal|       → d(error)/d(pred) = ±1
# Cross-entropy: error = -log(pred)      → d(error)/d(pred) = -1/pred
# Different error formula → different bowl shape → different gradient → network learns different things
# Trask Ch.11: "Meaning is derived from loss."

The 5-Line Chain — Every Term Annotated

Exactly where each quantity lives and what it carries across spaces.
Output Space pred          = input × weight FORWARD PASS — input space × weight space → output space. The network's current guess.
Output Space error         = (pred − goal)² MEASUREMENT ONLY — how far up the bowl. NOT used in weight update. Squaring = always positive + amplifies big misses.
Output Space delta         = pred − goal SLOPE OF BOWL — signed. Negative = left of min = must increase pred. IS d(error)/d(pred) ÷ 2.
→ Weight Space weight_delta  = delta × input CHAIN RULE CROSSING — output-space error translated into weight-space correction. input = d(pred)/d(weight) = the bridge.
Weight Space weight       -= alpha × weight_delta GRADIENT DESCENT — move through weight space. Subtract = opposite to slope = downhill. Alpha controls step size.

Two Layers — The Chain Gets Longer

The chain rule extends backward through every layer. This IS backpropagation.
input×weight₁=hidden×weight₂=pred→(pred−goal)²=error ← forward pass → 
# ── Forward pass ───────────────────────────────────────────────────────────
hidden = input * weight1           # step 1
pred   = hidden * weight2          # step 2
error  = (pred - goal) ** 2        # step 3 — monitoring only

# ── Backward pass — chain rule at each junction ────────────────────────────

# STEP 1 — output delta (same as single-layer)
delta_output = pred - goal         # d(error)/d(pred) at output node

# STEP 2 — gradient for weight₂ (the output-side weight)
grad_w2 = delta_output * hidden    # chain rule: delta × d(pred)/d(weight₂)
#                                  # hidden is the INPUT to weight₂

# STEP 3 — pass error BACKWARD through weight₂ to reach hidden layer
delta_hidden = delta_output * weight2  # d(error)/d(hidden)
# weight₂ IS d(pred)/d(hidden), because: pred = hidden × weight₂
# This is the moment error crosses from output layer into the hidden layer

# STEP 4 — gradient for weight₁ (the input-side weight)
grad_w1 = delta_hidden * input     # chain rule applied again
#                                  # input is the INPUT to weight₁

# ── Update both weights ─────────────────────────────────────────────────────
weight2 -= alpha * grad_w2         # output-side weight
weight1 -= alpha * grad_w1         # input-side weight

# The pattern: each weight's gradient = (incoming delta) × (local input)
# Incoming delta = delta from the layer ahead, passed back through that layer's weight

Why delta_hidden = delta_output × weight₂

This single line IS backpropagation. It is the chain rule applied at the hidden layer junction.
The full chain for weight₁
d(error)/d(weight₁)

= d(error)/d(pred)      ← 2×delta_output
  × d(pred)/d(hidden)   ← weight₂
  × d(hidden)/d(weight₁)← input

= 2×delta_output × weight₂ × input

= delta_hidden × input

where:
  delta_hidden = delta_output × weight₂
Why d(pred)/d(hidden) = weight₂?
pred   = hidden × weight₂
weight₂ is fixed, hidden varies
d(pred)/d(hidden) = weight₂

Same pattern as:
pred   = input × weight
d(pred)/d(weight) = input
The key insight — what backpropagation IS
Each layer multiplies incoming delta by its connecting weight
delta_hidden = delta_output × weight₂. The weight is the local slope at that junction.
Error travels backward, accumulating the chain product
Output node → hidden node → input node. One multiplication per layer per step backward.
Any weight's gradient = product of all slopes from that weight to output
d(error)/d(weight₁) = 2δ × weight₂ × input. Three links, three slopes multiplied.
Backpropagation is efficient because of sharing
delta_hidden is computed once and shared to all weights in that layer. Never repeated.

Input Space · Weight Space · Output Space

Where each computation lives — and how the chain rule crosses between them.
Input Space
Your training data. Fixed per step.
input = [8.5, 0.65, 1.2]

One point per observation.
N dims = N features.
Does NOT change
during training.

Role in chain rule:
  d(pred)/d(weight) = input
  Input is the lever arm.
  Large input → big weight_delta.
Output Space
Predictions and errors. Where loss lives.
pred  = 0.85
error = 0.023  (monitoring)
delta = -0.15  (signed slope)

Error and delta both
computed here.

Backprop STARTS here.

d(error)/d(pred)
  = 2 × delta = -0.30
This is the seed gradient.
Weight Space
Learned parameters. Changes every step.
weight = 0.1     (before)
grad   = -1.275  (weight_delta)
weight = 0.11275 (after)

Gradient descent
moves here.

d(error)/d(weight)
  = -0.30 × 8.5 = -2.55
  = weight_delta × 2

Each step = one move
through weight space.
The chain rule crosses spaces: error measured in output space → delta × input → weight_delta in weight space. The input value is the bridge between them.

Full Annotated Code — Every Line Explained

Single-layer network: forward pass + complete chain rule backward pass with all three spaces labelled.
# ── Setup — three spaces ────────────────────────────────────────────────────
input  = 8.5    # INPUT SPACE — fixed per step, the lever arm
goal   = 1.0    # OUTPUT SPACE — the target we are trying to reach
weight = 0.1    # WEIGHT SPACE — the learnable parameter
alpha  = 0.01   # step size in weight space

# ── Forward Pass ─────────────────────────────────────────── INPUT×WEIGHT→OUTPUT
pred  = input * weight          # = 8.5 × 0.1 = 0.85

# ── Error ──────────────────────────────────── OUTPUT SPACE (monitoring only)
error = (pred - goal) ** 2      # = (0.85−1.0)² = 0.023  — how far up the bowl
                                # DEAD END — not used in weight update

# ── Backward Pass — chain rule ─────────────────────────────────────────────

delta        = pred - goal      # = −0.15  | d(error)/d(pred) ÷ 2 | OUTPUT SPACE
                                # sign:  negative → left of min → must increase pred
                                # magn:  0.15 → moderate miss, moderate correction

weight_delta = delta * input   # = −0.15 × 8.5 = −1.275  | CROSSING TO WEIGHT SPACE
                                # delta     = d(error)/d(pred) — slope at output
                                # input     = d(pred)/d(weight) — lever arm
                                # product   = d(error)/d(weight) — full gradient ÷2

weight      -= alpha * weight_delta  # = 0.1−(0.01×−1.275) = 0.11275 | WEIGHT SPACE
                                # subtract: opposite to slope = downhill
                                # alpha: controls step size each iteration

# ── Verify improvement ──────────────────────────────────────────────────────
new_pred = input * weight       # = 8.5 × 0.11275 = 0.9584
new_err  = (new_pred - goal)**2 # = (0.9584−1.0)² = 0.0017  ← much smaller than 0.023 ✓
# One step of gradient descent reduced error by 93%. Direction was correct.
