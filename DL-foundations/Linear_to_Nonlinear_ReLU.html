Step 1 · What "Linear" Means

The two tests every linear function must pass

"Linear" isn't a vibe — it's a precise mathematical property with two checkable conditions.

1. Additivity

f(x1 + x2) = f(x1) + f(x2)

Feeding in a sum gives the same result as summing the individual outputs.

2. Homogeneity

f(a·x) = a·f(x)

Scaling the input scales the output by exactly the same factor — including negative scalars.

If a function fails either test, it's nonlinear — full stop. This gives us a clean, mechanical way to check any function, rather than relying on "does it look like a curve."
Step 2 · The Collapse Problem

Why stacking linear layers never helps

No matter how many linear layers you chain, the result is still just one straight line.

The algebra

Layer 1: h = W1·x Layer 2: y = W2·h = W2·(W1·x) = (W2·W1)·x Let W_combined = W2·W1 → y = W_combined · x

Two matrix multiplications in a row are mathematically identical to one combined matrix multiplication.

10 linear layers

Still collapses to one effective matrix. Stacking depth adds zero extra representational power.

The fix needed

Something has to break this collapsibility — a function that cannot be re-expressed as a single matrix multiply. That's exactly the job of an activation function.

Step 3 · Meet ReLU

A threshold rule: keep it, or zero it

Rectified Linear Unit — possibly the simplest nonlinear function that works.

The rule

ReLU(z) = z if z > 0 ReLU(z) = 0 if z ≤ 0 (equivalently: ReLU(z) = max(0, z))
Two completely different behaviors stitched together at z = 0: flat (slope 0) on the left, rising (slope 1) on the right. That seam is where all the nonlinearity lives.
Step 4 · The Proof

Running ReLU through both tests

Concrete numbers — not hand-waving — showing exactly where linearity breaks.

Homogeneity test (scalar = −1)

z = 2, a = -1 ReLU(a·z) = ReLU(-2) = 0 a·ReLU(z) = -1 × ReLU(2) = -1 × 2 = -2 0 ≠ -2 → FAILS

Additivity test

z1 = 3, z2 = -5 ReLU(z1) + ReLU(z2) = 3 + 0 = 3 ReLU(z1 + z2) = ReLU(-2) = 0 3 ≠ 0 → FAILS
Why this matters mechanically: clipping negative values throws away information asymmetrically. The contribution of z2 = -5 simply vanishes when clipped — under true linearity it would have been preserved and able to partially cancel z1. That asymmetric information loss is the entire mechanism.
Step 5 · One Hinge

A single ReLU unit = one bend in the line

h = ReLU(w1·x + b1) is flat, then becomes a straight line, with the bend located wherever w1·x + b1 crosses zero.

Where the hinge sits

w1·x + b1 = 0 x = -b1 / w1 ← the hinge location

Changing b1 slides the hinge left/right. Changing w1 changes the steepness after the hinge.

One hinge alone still can't fit a curve like a parabola — it only gives you one bend. You need multiple hinges, placed at different locations, to approximate something more complex.
Step 5 · Many Hinges

Stitching hinges together into a curve

Sum several ReLU units, each with its own hinge location and steepness, and the result approximates any shape.

The sum

y = w2_1·ReLU(w1_1·x+b1_1) + w2_2·ReLU(w1_2·x+b1_2) + ... + b2

Each term contributes its own hinge. Different inputs activate different subsets of hinges — and only the active ones receive a gradient during training for that input.

This is the mechanical version of the universal approximation theorem: enough straight-line pieces, stitched at the right breakpoints, become indistinguishable from a smooth curve — without the network ever "understanding" curvature.
Worked Example

Fitting y = x² with two ReLU units

Setup

h1 = ReLU(w1_1·x + b1_1) ← handles x > 0 h2 = ReLU(w1_2·x + b1_2) ← handles x < 0 ŷ = w2_1·h1 + w2_2·h2 + b2

At x = 2 (only h1 active)

h1 = ReLU(2) = 2.0 h2 = ReLU(-2) = 0.0 ← clipped, zero gradient too ∂L/∂w1_2 = 0 (h2 untouched by this example)
The specialization mechanism: positive-x examples only ever update h1's weights; negative-x examples only ever update h2's weights. Each unit naturally specializes to the region of input space where it's switched on — nobody assigns these roles, gradient descent discovers them.
Step 6 · Beyond ReLU

Same idea, different shapes

ReLU isn't the only nonlinearity — every option breaks linearity its own way.

FunctionShapeWhere it breaks linearity
ReLUmax(0, z)Hard clip at zero — sharp hinge
Sigmoid1 / (1 + e⁻ᶻ)Smooth S-curve, squashes to (0, 1)
Tanh(eᶻ−e⁻ᶻ)/(eᶻ+e⁻ᶻ)Smooth S-curve, squashes to (−1, 1)
GELUz·Φ(z)Smooth, probabilistic gating — used in BERT/GPT
All four fail the additivity/homogeneity tests for the same underlying reason: each treats different regions of the input differently — clipping, squashing, or gating — in a way no single matrix multiplication could replicate.
Recap

How a threshold becomes a curve-fitter

The big picture

  • Linear means passing the additivity and homogeneity tests — stacking linear layers alone can never produce a function that fails them.
  • ReLU's asymmetric clipping (pass positive, zero negative) is enough to fail both tests — proven with concrete numbers, not intuition.
  • One ReLU unit creates exactly one hinge; many units, summed together, stitch into a piecewise-linear approximation of any curve.
  • Gradient descent naturally specializes each unit to the input region where it's active — nobody assigns this division of labor by hand.
  • Other activations (sigmoid, tanh, GELU) break linearity differently — but always by treating some regions of input differently from others.
