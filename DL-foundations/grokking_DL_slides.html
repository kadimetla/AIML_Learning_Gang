The Predict → Compare → Learn Loop

Trask Ch.3–4 — The master framework for all neural network training
1
PREDICT
Feed input through the network.
Weighted sum → output value.
2
COMPARE
Measure how wrong we are.
error = (pred − goal)²
3
LEARN
Adjust every weight by its share of the blame.
pred = input * weight # PREDICT
error = (pred - goal_pred) ** 2 # COMPARE — always positive
delta = pred - goal_pred # raw direction & amount missed
weight_delta = delta * input # LEARN — blame the weight
weight -= alpha * weight_delta # update — move opposite to slope

What does weight control?
w = 2.0 doubles the input — amplify
w = 0.5 halves the input — scale down
w = 0.0 zeroes the input — silence
w = −1.0 flips the input — reverse
"Weight is a volume knob — it amplifies or suppresses each input's influence on the prediction." — Trask

Hot & Cold vs Gradient Descent

Ch.4 — Two strategies for finding the right weight. One is elegant.
🌡 Hot & Cold (naive)
→ Try weight+step, measure error
→ Try weight−step, measure error
→ Keep whichever direction is lower
→ Repeat until error ≈ 0
✗  3 predictions per step (wasteful)
✗  Step size is arbitrary
✗  Ignores how BIG the error is
→
📐 Gradient Descent (smart)
→ Compute slope of error curve directly
→ One step, correct direction every time
→ Step size scales with error magnitude
→ Works for millions of weights
✓  1 prediction per step
✓  Direction + amount from math
✓  Derivative tells us the slope
The bowl analogy: error = ((0.5 × weight) − 0.8)² plots a U-shape. The slope at any weight = how much error changes. Move opposite to slope → descend to zero error. That's Gradient Descent.

Error → Delta → Weight Update

Ch.4 — The exact 5-step computation. Every term has a purpose.
1
pred
input × weight  =  8.5 × 0.1  =  0.85
Forward pass output
2
error
(pred − goal)²  =  (0.85 − 1)²  =  0.023
Always positive; amplifies big misses
3
delta
pred − goal  =  0.85 − 1  =  −0.15
"Pure error" — raw direction & amount
4
weight_delta
delta × input  =  −0.15 × 8.5  =  −1.275
Stopping, reversal, scaling
5
new weight
weight − α × weight_delta  =  0.1 − (0.01×−1.275)  =  0.113
α = 0.01 controls step size

Three Properties of weight_delta = delta × input

Ch.4 — Why we multiply by input. Each property fixes a real problem.
1
STOPPING
If input = 0, weight_delta = 0.
No learning when input is silent. Changing weight × 0 input changes nothing about the prediction — there's no point moving the weight.
input = 0 → weight_delta = −0.15 × 0 = 0
2
NEGATIVE REVERSAL
If input is negative, flip the direction.
Negative input reverses the relationship between weight and prediction. Multiplying by it automatically corrects the update direction.
input = −2 → weight_delta = −0.15 × −2 = +0.30
3
SCALING
Large input → large weight_delta.
A weight connected to a large input had more influence on the error. It deserves a proportionally larger correction to undo its contribution.
input = 8.5 → weight_delta = −0.15 × 8.5 = −1.275

Alpha: The Learning Rate

Ch.4–5 — The single most important hyperparameter. Get it wrong and nothing trains.
💥 α too large
Overshooting
Weight jumps past minimum.
Error oscillates or grows.
Network never converges.
✓ α just right
Converging
Weight steps smoothly toward minimum.
Error decreases every step.
Network converges reliably.
🐢 α too small
Crawling
Weight barely moves each step.
Training takes forever.
Practically unusable in practice.
weight -= alpha * weight_delta    # alpha = 0.01 is a common starting point. Try 0.1 → if error oscillates, halve it.

Experiment: Freeze One Weight — What Happens?

Ch.5 — A thought experiment that reveals a dangerous property of neural networks.
The setup
Freeze weight[0] (toes). Train only weight[1] and weight[2].
# zero out this weight's update
weight_deltas[0] = 0
Result
Network still converges to error ≈ 0 using only weight[1] and weight[2].
Then unfreeze weight[0]…
It won't move! error = 0 means weight_delta = 0. The weight is permanently frozen out — even if it would be a powerful predictor.
Why this matters
Dead weight problem
Network can ignore a powerful input if it finds a shortcut using other weights first.
Error surface insight
All weights share a single error value. When one reaches minimum, all do — the error surface is N-dimensional.
Overfitting warning
Always test on held-out data. The network may memorize training patterns without learning the true signal.

Chapter 6: Streetlight Problem → Backpropagation

Networks learn correlation — and a hidden layer lets them learn non-linear patterns.
The Streetlight Problem
Foreign country. Which lights mean WALK?
STOP
WALK
STOP
WALK
STOP
Middle light = perfect predictor. The network must find this correlation automatically.
Why We Need a Hidden Layer
XOR problem
No single line separates all patterns. Hidden layer creates non-linear decision boundaries.
Backpropagation
Error flows backward from output → hidden layer. Each hidden weight gets its blame via chain rule.
Chain rule
weight_delta = delta_out × w_out × input — error attribution across layers.
Overfitting risk
More power → more risk of memorizing. Always validate on held-out data.
