Where Does −2x·e
Actually Come From?

Every gradient descent update has that factor of 2 and that lone x sitting in it. Neither is arbitrary — both fall straight out of the chain rule applied to one squared term. Let's build it from nothing.

→ one function inside another. that's all the chain rule ever is.

SET UP THE PROBLEM

Name the Error Before You Square It

Start from the per-point loss for linear regression:

L = (y − wx − b)²

Give the inside a name — this single move is what makes the chain rule visible instead of hidden:

e = y − wx − b
so now   L = e²

why bother naming it?

Because L doesn't touch w directly. w can only affect L by first changing e, and only then does squaring react.

That's a chain: w → e → L. We want ∂L/∂w, and the chain rule is the tool that walks a derivative down a chain like this, link by link.

THE TOOL

The Chain Rule: Multiply the Ripples

∂L/∂w  =  ∂L/∂e  ·  ∂e/∂w

Nudge w a tiny bit. That nudge ripples into e (Piece B), and that change in e ripples into L because L = e² (Piece A). The total effect is those two ripples multiplied together.

two separate, easy questions instead of one hard one

SOLVE EACH PIECE

Piece A and Piece B, One at a Time

PIECE A

How does L react to e?

L = e²

Plain power rule: bring the exponent down, drop it by one.

∂L/∂e = 2e
PIECE B

How does e react to w?

e = y − wx − b

y → no w, derivative 0
−wx → x is just a fixed multiplier on w, derivative −x
−b → no w, derivative 0

∂e/∂w = −x
COMBINE

Multiply the Two Pieces Back Together

1
∂L/∂w = (∂L/∂e) · (∂e/∂w) = (2e) · (−x)
2
= −2x·e
3
substitute e back in  →  ∂L/∂w = −2x(y − wx − b)

Same recipe for b — except ∂e/∂b = −1 (no x multiplying it), so ∂L/∂b = −2e. That's the entire reason w's update scales with x and b's doesn't.

THE TAKEAWAY

Two Amplifiers Stacked on Top of Each Other

The 2 exists because squaring amplifies change proportional to the current value — that's just what the power rule says about e². It would appear no matter what was inside the parentheses.

The x exists because w doesn't act alone inside e — it's scaled by x first (−wx). Whatever multiplies w on the way in is exactly what shows up in its gradient.

chain rule, in one sentence: multiply how much each link amplifies the one before it.
