Step 1 · Forward Pass

What a network does before it learns anything

A forward pass is just repeated matrix multiplication + a nonlinearity, layer after layer.

x

W·x+b

→

Activation

ŷ

The linear step

Every layer computes a weighted sum of its inputs plus a bias:

z = W·x + b

W and b are the learnable parameters — everything backprop will eventually adjust.

The nonlinearity

Without an activation function, stacking layers would just collapse into one big linear function. A nonlinearity (ReLU, sigmoid, etc.) lets the network represent curves, not just lines.

a = σ(z) e.g. σ(z) = max(0, z) ← ReLU
Step 2 · Loss Function

Turning "wrong" into a number you can differentiate

The loss function is the single quantity backpropagation is trying to shrink.

Mean Squared Error (regression)

L = (ŷ − y)²

Penalizes the squared distance between prediction ŷ and true value y. Bigger misses get punished disproportionately more.

Cross-Entropy (classification)

L = −log(p_correct_class)

Penalizes low confidence in the correct class. If the model assigns the true class only 1% probability, the loss is large; near 100%, loss approaches zero.

Why it has to be differentiable: backpropagation works by computing the slope (gradient) of the loss with respect to every weight. If the loss function isn't smooth and differentiable, there's no slope to compute — and no signal to learn from.
Step 3 · The Chain Rule

The one calculus idea that makes this all work

Backpropagation is the chain rule, applied repeatedly, layer by layer, in reverse.

The idea in one line

If y depends on x through an intermediate variable u, then the effect of a small change in x on y is the product of each step's local effect:

dy/dx = dy/du × du/dx

Why neural nets need this

A network is a long chain of nested functions: loss(activation(linear(activation(linear(x))))). To know how a weight buried deep in layer 1 affects the final loss, you have to multiply together the local derivative at every layer in between.

The mechanical consequence

This is why backprop runs backward — from the loss toward the input. Each layer only needs to know two things: its local derivative, and the gradient handed to it from the layer after it.

Step 4 · Toy Network

A tiny network we can compute by hand

One input, one hidden neuron, one output neuron — small enough to trace every number.

Architecture

Input: x = 2.0 Hidden layer: h = ReLU(w1·x + b1) Output layer: ŷ = w2·h + b2 Loss: L = (ŷ − y)², target y = 10.0

Initial parameters

w1 = 1.5, b1 = 0.0 w2 = 2.0, b2 = 0.0

These are exactly what backprop will adjust — there's nothing else "learnable" in this network.

We'll run one full forward pass, compute the loss, then run backward through both layers to see exactly how w1 and w2 get corrected.
Step 4 · Toy Network

Forward pass: plugging in the numbers

HIDDEN PRE-ACT
z1 = w1·x + b1 = 1.5×2.0 + 0.0 = 3.0
HIDDEN ACTIVATION
h = ReLU(3.0) = 3.0 (positive, so ReLU passes it through)
OUTPUT
ŷ = w2·h + b2 = 2.0×3.0 + 0.0 = 6.0
LOSS
L = (ŷ − y)² = (6.0 − 10.0)² = 16.0
The network predicted 6.0 when the true answer was 10.0 — a loss of 16.0. Backprop's job: figure out exactly how to nudge w1 and w2 to shrink that number.
Step 5 · Backward Pass

Backward step 1 — the output layer

We start at the loss and move backward, computing one local derivative at a time.

∂L/∂ŷ — how loss reacts to the prediction

L = (ŷ − y)² ∂L/∂ŷ = 2(ŷ − y) = 2×(6.0 − 10.0) = −8.0

Negative means: increasing ŷ would decrease the loss (makes sense — we undershot).

∂L/∂w2 — how loss reacts to w2

ŷ = w2·h + b2 → ∂ŷ/∂w2 = h = 3.0 ∂L/∂w2 = ∂L/∂ŷ × ∂ŷ/∂w2 = −8.0 × 3.0 = −24.0

This is the chain rule in action — multiplying the loss's sensitivity to ŷ by ŷ's sensitivity to w2.

We also need ∂L/∂h = ∂L/∂ŷ × ∂ŷ/∂h = −8.0 × w2 = −8.0 × 2.0 = −16.0 — this is the gradient we hand down to the hidden layer next.
Step 5 · Backward Pass

Backward step 2 — the hidden layer

Same chain rule, one layer further back — this time passing through the ReLU activation too.

∂h/∂z1 — the ReLU derivative

ReLU'(z) = 1 if z > 0, else 0 z1 = 3.0 (positive) → ∂h/∂z1 = 1

ReLU just passes the gradient through unchanged when the input was positive — and would have zeroed it out entirely if z1 had been negative.

∂L/∂w1 — how loss reacts to w1

z1 = w1·x + b1 → ∂z1/∂w1 = x = 2.0 ∂L/∂w1 = ∂L/∂h × ∂h/∂z1 × ∂z1/∂w1 = (−16.0) × 1 × 2.0 = −32.0

Three terms multiplied together — the full chain from loss, through the activation, through the linear layer, down to w1.

This is the whole algorithm: at every layer, multiply the gradient handed down from above by that layer's own local derivative, and pass the result further back. No layer needs to "see" the loss directly — only the gradient relayed to it.
Step 6 · Weight Update

Turning gradients into an actual correction

Gradient descent: move every weight a small step in the direction that reduces the loss.

The update rule

w_new = w_old − learning_rate × ∂L/∂w

The gradient tells us the direction of steepest increase in loss — so we subtract it to move in the direction that decreases loss.

Updating w2 (learning rate = 0.01)

w2_new = 2.0 − 0.01×(−24.0) = 2.0 + 0.24 = 2.24

Updating w1 (learning rate = 0.01)

w1_new = 1.5 − 0.01×(−32.0) = 1.5 + 0.32 = 1.82
Both weights increased — correctly, since the network undershot the target (predicted 6.0, needed 10.0). A second forward pass with these new weights will produce a prediction closer to 10.0, and the loss will be lower.
Recap

What backpropagation actually is

PhaseWhat happensDirection
Forward passInput flows through layers, producing a prediction and a lossInput → Output
Backward passChain rule applied repeatedly to compute ∂Loss/∂(every weight)Output → Input
Weight updateEach weight nudged opposite its gradient, scaled by learning rateApplied everywhere at once

The big picture

  • Backprop is just the chain rule, applied once per layer, moving from the loss backward to the inputs.
  • Every layer only needs its own local derivative and the gradient handed to it from above — no global view required.
  • Gradients tell you direction and magnitude; gradient descent decides how big a step to actually take.
  • Repeat across millions of examples, and weights that are statistically useful for reducing loss survive and strengthen — this is the entire mechanism behind "learning."
