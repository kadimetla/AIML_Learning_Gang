CHAPTER 1 · RECAP

One Neuron Is Linear Regression
Wearing a Costume

no hidden layer = nothing to bend the line

Strip away the "neural network" framing: with zero hidden layers, this is exactly ŷ = w₁·GrLivArea + w₂·OverallQual + ... + b — ordinary least squares, just trained by gradient descent instead of the Normal Equation.

It can only ever draw a flat hyperplane through feature space. It can add the effect of features together. It cannot let one feature's effect depend on another's.

TRAP

Quality and Size Don't Just Add.
They Multiply.

We built SalePrice with a real interaction baked in: a high-OverallQual house gets extra value from every additional square foot — quality amplifies size, it doesn't just sit beside it.

"two features ganging up" — no single weight can encode that

TRAP, VISUALIZED

A Straight Line Cannot Fold

best straight line: misses both ends and the middle

several ReLU bends stitched together: tracks the curve

Every hidden neuron with a ReLU contributes one possible "kink." Stack enough of them and their sum can trace curves no single line ever could — that's the entire trick behind Part 2.

FIX

Give the Network Hands:
Hidden Layers + ReLU

A hidden neuron is still just w·x + b — but pass it through ReLU(z) = max(0, z) first, and now it "turns on" only past some threshold.

32 of those, each tuned to switch on at a different combination of GrLivArea and OverallQual, and their weighted sum in the next layer can approximate "quality multiplies size" — without ever being told to multiply anything.

forward pass, written out:

h1 = ReLU( X · W1 + b1 )
h2 = ReLU( h1 · W2 + b2 )
ŷ  = h2 · W3 + b3

each layer's output becomes the next layer's input — depth is just function composition.

The Architecture, Layer by Layer

8 features → 32 neurons (ReLU) → 16 neurons (ReLU) → 1 price. Each arrow is a weight; each circle adds a bias and a nonlinearity.

BUILD

What "Training" Actually Loops Through

  • 1. Forward push a batch of houses through the network → predicted prices
  • 2. Loss compare to real SalePrice with MSE
  • 3. Backward compute ∂loss/∂w for every weight, layer by layer, back through the chain rule
  • 4. Step Adam nudges every weight a little against its gradient
  • 5. Repeat for 400 epochs, watching train AND test loss

real numbers from the run:

epoch  0   train 1.142  test 1.096
epoch 100  train 0.016  test 0.018
epoch 200  train 0.012  test 0.017
epoch 300  train 0.011  test 0.017

both curves drop together and stay close — that closeness is what "learning the pattern, not the rows" looks like.

CHAPTER 2 · TRAP

More Capacity, Less Discipline:
The Network Starts Memorizing

Swap in a much wider network — 256 → 256 → 128 neurons — with no regularization, on the same ~1,160 training houses.

final train MSE: 0.0011
final test  MSE: 0.0205
gap (test − train): 0.0194

train keeps falling; test stalls — the growing gap IS overfitting, as a number

WHY THIS HAPPENS

Capacity vs. Data: An Honest Comparison

A 256-wide layer has tens of thousands of weights. We're training on ~1,160 houses. There is more than enough room in that weight space to carve out a tiny, idiosyncratic rule for almost every individual training house — "if GrLivArea is exactly 1,748 and OverallQual is 8, predict exactly $315,541" — instead of the general relationship. Gradient descent doesn't know the difference between signal and a house's specific noise; it will happily fit both if you let it run long enough with enough free parameters.

capacity isn't free. it has to be paid for with discipline.

FIX

Four Mechanisms, Four Different Jobs

  • L2 (decay) penalizes Σw² — pushes toward many small weights instead of a few huge ones
  • L1 penalizes Σ|w| — pushes weights to exactly zero, a built-in feature selector
  • Dropout randomly zeroes neurons during training — no neuron gets to be indispensable
  • BatchNorm normalizes activations per layer — stabilizes the distribution depth has to pass through

shrinkage · sparsity · redundancy · stability — none of these is "the same trick twice"

SEE IT

Dropout, Live: Click Neurons to Drop Them

Each batch, ~30% of hidden neurons (dimmed) vanish. The remaining ones must carry the signal alone — over many batches, no single neuron can become a single point of failure.

WRAP-UP

Three Ideas to Carry Forward

  • Depth lets a network build the interaction terms you didn't hand-engineer — that's what hidden layers + nonlinearity buy you.
  • Capacity is a loan — without enough data or discipline, it gets spent on memorizing rows instead of learning the relationship.
  • Regularization is plural — L1, L2, dropout, and batch norm fight overfitting through genuinely different mechanisms, not one trick rebranded four times.
